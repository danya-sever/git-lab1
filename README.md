# Git Lab 1

Учебный проект для изучения системы контроля версий Git.

## Структура проекта

- `.github/` — настройки GitHub, шаблон Pull Request и workflow автоматических проверок.
- `.gitignore` — список файлов, которые Git не должен отслеживать.
- `myfile.txt` — описание системы контроля версий Git.
- `ourfile.txt` — дополнительные материалы по работе с Git.
- `yourfile.txt` — информация о ветках и их назначении.
- `README.md` — описание проекта и инструкция по его запуску.

## Запуск

Для получения проекта выполните команду:

git clone https://github.com/danya-sever/git-lab1.git
