# Git Lab 1

Учебный проект для изучения системы контроля версий Git.

## Структура проекта

Проект содержит текстовые файлы, используемые для изучения Git, а также шаблон Pull Request и workflow автоматических проверок GitHub Actions.

## Запуск

Для получения проекта выполните команду:

git clone https://github.com/danya-sever/git-lab1.git
